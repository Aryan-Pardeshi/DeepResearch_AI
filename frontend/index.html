Human-In-The-Loop

AI does the research.
You stay in control.

Most AI tools attempt to write entire papers in a single ungrounded pass. DeepResearch uses LangGraph interrupt() calls to pause the graph at four critical decision gates.

Provide feedback in natural language, request revisions, or approve with one click. The state machine never commits to downstream research without your explicit consent.

Technical Architecture

Built as a real research system.

Engineered for reproducibility, state persistence, and zero vendor lock-in.

LangGraph State Machine
Resumable DAG execution with native interrupt() HITL and Send() parallelization.
Global Scholarly APIs
Direct querying against OpenAlex, Semantic Scholar, arXiv, Unpaywall, Europe PMC, and CORE.
FastAPI + SSE Streaming
High-throughput asynchronous backend streaming live token-by-token progress and agent states.
SQLite Checkpointing
Persistent graph state surviving backend restarts and browser refreshes with zero data loss.
Bring Your Own Key (BYOK)
Compatible with any OpenAI-style gateway: DeepSeek, OpenAI, Ollama, vLLM, and LiteLLM.
Zero Data Leakage
All API keys and research sessions stay strictly on your local machine in your local .env file.
